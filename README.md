# resumo_do_lab
Este repositório contém o resumo das lições aprendidas durante o desenvolvimento do lab na DIO.

Computação em nuvem:
Entrega de serviços sob demanda (servidores, armazenamento, redes, software) via internet.
Modelos de implantação:
Pública (Azure, AWS, Google Cloud)
Privada (infraestrutura dedicada)
Híbrida (combinação de pública + privada)
Benefícios: escalabilidade, economia de custos, alta disponibilidade, segurança.
Serviços do Azure
Computação: Máquinas Virtuais (VMs), Azure App Services, Azure Kubernetes Service (AKS).
Armazenamento: Blob Storage, Azure Files, Disk Storage.
Redes: Virtual Network (VNet), Load Balancer, Azure DNS.
Banco de Dados: Azure SQL Database, Cosmos DB.
Modelos de Serviço na Nuvem
IaaS (Infraestrutura como Serviço): Controle sobre VMs, redes (ex: Azure VMs).
PaaS (Plataforma como Serviço): Foco no desenvolvimento (ex: Azure App Services).
SaaS (Software como Serviço): Aplicativos prontos (ex: Office 365).
Segurança e Conformidade no Azure
Defesa em profundidade: Múltiplas camadas de segurança (rede, dados, identidade).
Azure Active Directory (Azure AD): Gerenciamento de identidade e acesso.
Políticas de conformidade: GDPR, ISO, HIPAA.
Gerenciamento de Custos no Azure
Azure Pricing Calculator: Estimar custos.
Azure Cost Management: Monitorar gastos.
Fatores que impactam custos: Região, tipo de recurso, tráfego de dados.
Governança e SLA
Azure Policy: Aplicar regras em recursos.
SLA (Service Level Agreement): Garantia de disponibilidade (ex: 99,9% para VMs).
Serviços de Monitoramento
Azure Monitor: Coletar e analisar dados de desempenho.
Azure Service Health: Verificar status de serviços.
